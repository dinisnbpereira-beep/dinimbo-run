# Dinimbo Run 🦎

An endless runner starring a yellow axolotl hopping over colorful blocks.

## Play
Open `index.html` in any browser — no build step, no dependencies.

## Controls
- **Space / ↑ / W / click / tap** — jump (hold for a higher hop)
- One extra mid-air double jump is allowed
- Blocks get faster as your score climbs; best score is saved locally
